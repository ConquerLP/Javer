# Javer

Private fork of Javer reduced to two command-line tools: compiler and VM.

## Requirements

- JDK 21 or newer

## Build

```powershell
.\mvnw.cmd clean package
```

This builds:

- `Compiler/target/Compiler-1.0-SNAPSHOT-all.jar`
- `VM/target/VM-1.0-SNAPSHOT-all.jar`

## Run

Compile a `.javer` source file to `.jbc` bytecode:

```powershell
java -jar Compiler\target\Compiler-1.0-SNAPSHOT-all.jar --in-file input.javer --out-file output
```

Run the generated bytecode:

```powershell
java -jar VM\target\VM-1.0-SNAPSHOT-all.jar output.jbc
```

Compiler options:

```text
--in-file, -i
--out-file, -o
--dump-lexer
--dump-ast
--dump-symboltable
```

VM options:

```text
--stack-size <size>
--stack-size=<size>
--dump-on-error
-h, --help
```
